1.先跑一遍quicktest，然后进入docker（可以先尝试第二步，不行的话再返回跑这个）

cd ~
mkdir -p ~/finn_tmp

cd ~
git clone https://github.com/Xilinx/finn.git

cd ~/finn

export FINN_BUILD_DIR=~/finn_tmp
export FINN_HOST_BUILD_DIR=~/finn_tmp

docker version
docker ps

./run-docker.sh quicktest


2.进入docker就可以运行python文件了

cd ~/finn
export FINN_BUILD_DIR=~/finn_tmp
./run-docker.sh


3.zip压缩包放到my_build_2文件夹中然后解压，解压后会看到两个文件，deeponet_u250_int4_qonnx.onnx,step4_convert_qonnx_to_finn.py
运行以下代码，完成后会生成deeponet_u250_int4_qonnx_finn.onnx，将其更名为model.onnx,记得把旧的model.onnx删掉！！！！

cd my_build_2
python step4_convert_qonnx_to_finn.py --qonnx_in deeponet_u250_int4_qonnx.onnx


4.接下来就开始build dataflow,先检查环境

cd /home/xband/finn/my_build_2

export FINN_XILINX_PATH=/opt/Xilinx
export FINN_XILINX_VERSION=2022.2
export VIVADO_PATH=/opt/Xilinx/Vivado/2022.2
export VITIS_PATH=/opt/Xilinx/Vitis/2022.2
export HLS_PATH=/opt/Xilinx/Vitis_HLS/2022.2
export PLATFORM_REPO_PATHS=/opt/xilinx/platforms
#export NUM_DEFAULT_WORKERS=1 (add it if the system is shutted down)

source /opt/Xilinx/Vivado/2022.2/settings64.sh
source /opt/Xilinx/Vitis/2022.2/settings64.sh
source /opt/Xilinx/Vitis_HLS/2022.2/settings64.sh


5.开始run my_build_2这一步会花费大概两个半小时祝你们好运
