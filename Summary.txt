## Project Summary

The aim of this project is to develop a physics-informed neural network (PINN)-based optical fibre signal propagation model and investigate its suitability for FPGA acceleration. The model combines data-driven learning with the governing nonlinear Schrodinger equation (NLSE), using SSFM-generated data together with a DeepONet-style architecture. The overall objective is to achieve a solution that is both physically meaningful and deployable in a hardware-oriented environment.

At the current stage, the end-to-end implementation flow has been completed on the university machines. This includes model training, evaluation, deployment-oriented transformation, and successful completion of the full 19-step FINN dataflow build. In particular, the later build stages, including bitfile synthesis, PYNQ driver generation, and deployment packaging, were completed successfully. This demonstrates that the project has progressed beyond software-only modelling and reached a completed hardware deployment build stage for the Alveo U250 target.

The repository therefore now contains not only the model development work, but also the completed deployment flow and the build inputs required for FINN dataflow compilation, including `model.onnx` and `dataflow_build_config.json`. However, successful completion of the FINN build does not by itself prove that the deployed FPGA path reproduces the expected waveform numerically. The current verification path is therefore to generate one known `input.npy`, keep the matching SSFM reference output in `ssfm_output.npy` and `verification_case.npz`, and compare those reference tensors against the decoded output returned by the FPGA runtime. Only after that comparison can the deployment be described as functionally validated on hardware. Further details of the dataflow process are documented in the accompanying text files in this repository.
